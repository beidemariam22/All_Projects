## 🚀 About Me

I am a passionate robotics engineer focused on building intelligent, transparent, and trustworthy robotic systems. My interests lie in the intersection of machine learning and human-robot interaction (HRI), particularly in developing adaptive control systems for assistive robotics.

In my Master's thesis, I designed a machine learning-based control framework for upper limb exoskeletons using biosignal (sEMG) inputs and ROS integration. My long-term goal is to contribute to safe and explainable AI in human-centered robotics.
